안드로이드에 설치

설치 파일을 받아 바로 설치해요. 1분이면 끝나요.

!
카카오톡·인스타그램 안에서 열린 화면에서는 다운로드가 안 될 수 있어요. 오른쪽 위 ⋮ 메뉴에서 다른 브라우저로 열기(Chrome)를 눌러주세요.
설치 파일 받기 약 120KB
  1. 위 버튼을 눌러 다운로드

    "이 유형의 파일은 기기에 해를 끼칠 수 있습니다" 같은 경고가 뜨면 다운로드를 누르세요. 스토어 밖에서 받는 파일이라 뜨는 안내예요.

  2. 다운로드한 파일 열기

    화면 아래 완료 알림의 열기를 누르세요. 알림을 놓쳤다면 내 파일 → 다운로드에서 스테이크.apk를 누르면 돼요.

  3. "출처를 알 수 없는 앱" 허용

    처음 한 번만 나와요. 설정을 누르고 이 출처 허용을 켠 뒤 뒤로 돌아오세요.

  4. 설치 누르기

    Play 프로텍트가 "확인되지 않은 앱"이라고 하면 세부정보 더보기 → 무시하고 설치를 누르세요. 개인이 만든 앱이라 뜨는 안내예요.

  5. 열기

    설치가 끝나면 앱 목록에 주황색 스톱워치 아이콘 스테이크가 생겨요. 처음 열 때 알림 허용을 눌러야 화면이 꺼져도 알람이 울려요.

아이폰에 설치

사파리에서 앱 페이지를 연 뒤 홈 화면에 추가하면 앱처럼 쓸 수 있어요. 앱스토어는 필요 없어요.

!
지금은 카카오톡·인스타그램 같은 앱 안에서 열려 있어서 홈 화면에 추가를 할 수 없어요. 사파리로 열어주세요.
사파리로 열기
복사한 링크를 사파리 주소창에 붙여넣거나, 화면 아래 ⋯·공유 메뉴에서 Safari로 열기를 찾아 누르세요.
사파리에서 앱 페이지 열기
  1. 위 버튼으로 앱 페이지 열기

    꼭 사파리에서 열어야 해요. 스테이크 화면이 나오면 다음으로 넘어가세요.

  2. 공유 버튼 누르기

    화면 아래(또는 주소창 옆)의 공유를 누르세요. 공유 버튼이 안 보이면 ⋯ 버튼을 먼저 누르면 나와요.

  3. "홈 화면에 추가" 선택

    메뉴를 아래로 내리면 ⊕ 홈 화면에 추가가 있어요. 안 보이면 더 보기를 눌러 찾으세요.

  4. "웹 앱으로 열기" 켜고 추가

    이름은 스테이크 그대로 두고, 웹 앱으로 열기 스위치가 있으면 켜둔 채 오른쪽 위 추가를 누르세요.

  5. 홈 화면에서 실행

    주황색 스톱워치 아이콘이 생겨요. 누르면 주소창 없이 앱처럼 열리고, 한 번 연 뒤에는 인터넷이 없어도 쓸 수 있어요.

휴대폰으로 이 페이지 열기
카메라로 QR 코드를 찍으면 휴대폰에서 바로 설치할 수 있어요.

업데이트는 어떻게 하나요?

안드로이드: 이 페이지에서 설치 파일을 다시 받아 설치하면 기존 앱 위에 덮어써져요. 고른 설정은 그대로 남아요.

아이폰: 따로 할 건 없어요. 앱을 열면 새 버전을 받아두고, 완전히 닫았다 다시 열면 바뀌어요.

화면이 꺼져도 알람이 울리나요?

안드로이드: 네. 굽는 동안 화면이 꺼지지 않게 해두고, 다른 앱을 보고 있어도 뒤집을 때마다 알림이 울려요. 처음 열 때 알림을 허용해 주세요.

아이폰: 홈 화면 앱은 화면이 꺼지거나 다른 앱으로 가면 소리를 낼 수 없어요. 굽는 동안에는 스테이크 화면을 켜둔 채로 두세요. 무음 모드에서는 삐 소리가 작게 날 수 있어요.

앱을 지우려면요?

다른 앱과 똑같아요. 홈 화면에서 아이콘을 길게 눌러 삭제(아이폰) 또는 제거(안드로이드)를 누르세요.
